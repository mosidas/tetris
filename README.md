# tetris

デスクトップ版のテトリス。

## 動作環境

- Windows・macOS・Linux

## インストール

配布物は無い。ソースから起動する。

1. .NET SDK 10.0 以上をインストールする。
2. リポジトリをクローンする。
3. リポジトリのルートで `dotnet run --project Tetris.Avalonia` を実行する。

## 使い方

開始・一時停止・終了のキーは画面に表示される。プレイ中は次のキーで操作する。

| キー | 操作 |
| :- | :- |
| ← / → / ↓ | 移動 |
| ↑ | ハードドロップ |
| Z / X | 左回転 / 右回転 |
| Space | ホールド |

## 開発

道具は「インストール」の 1. と同じである。テストは次のコマンドで実行する。

```sh
dotnet test Tetris.sln
```
